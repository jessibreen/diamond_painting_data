Painting editor

Diamond Painting with Data · for instructors

Regions click one, then paint

    Each region gets its own attribute values when the level is built, so the queries pick it out. Press 1–9 to switch regions.

    Tools

    Brush size

    Right-click a gem to pick up its region. Drag to paint.

    When you're done

    1. Click Save. In Chrome or Edge, choose the file with the same name in the repo's art/ folder to replace it. Other browsers download the file instead; move it into art/.
    2. Reload the game. If you started the site with python3 tools/serve.py, it rebuilds the levels for you. Otherwise run python3 tools/build_levels.py first, because the game reads the built files in levels/, not art/.
    3. Check the level’s box art.

    Glows and outlines that come from Select by Location (Levels 10, 11, 13) aren’t painted here; they’re worked out from the shapes you paint. Level 12’s picture comes from its pond, trail and spring layers, so it isn’t in this editor.
